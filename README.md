# 🎮 Gold Bomb Game (Java)

Gold Bomb is a simple **Java Swing-based mini game** where the player earns points by clicking gold icons while avoiding bombs.  
The game includes sound effects, background music, and a graphical user interface.

---

## 🕹️ Gameplay
- Gold appears randomly on the grid → **Click to earn points**
- Bomb appears randomly → **Clicking a bomb ends the game**
- Score increases dynamically
- Restart and Exit options after Game Over

---

## ✨ Features
- Java Swing GUI
- Randomized game logic
- Background music & sound effects
- Timer-based animations
- Restart and Exit controls

---

## 🛠️ Technologies Used
- **Java 21**
- **Java Swing**
- **AWT**
- **AudioSystem (WAV sounds)**
